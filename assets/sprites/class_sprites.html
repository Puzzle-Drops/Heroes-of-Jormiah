Integration with index.html

The CLASS_SPRITES object in this file's script is the source of truth. To wire it into the game, replace the if/else chain in drawV2Party (around line 7039 of index.html) with this lookup:

drawV2Party(ctx, x, y) {
  const time = Date.now() / 1000;
  const breathe = Math.sin(time * 2) * 0.5;
  const fn = CLASS_SPRITES[this.className];
  if (fn) fn(ctx, x, y, time, breathe);
}

The keys (Tank, Healer, etc.) are intentionally the unchanged internal className strings, so existing save data continues to work. Only displayName changes for the rename. See CLASS_REDESIGN_SPEC.md for the full implementation plan.

To add a new class sprite: define the function inside CLASS_SPRITES below (keyed by the new class's className), add a <article class="sprite-card"> entry in the matching family section above with data-class="..." matching the key, and remove the placeholder TODO card.
